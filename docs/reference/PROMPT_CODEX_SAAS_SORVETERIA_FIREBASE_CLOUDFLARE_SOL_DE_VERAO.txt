25. SECURITY RULES
======================================================================

Rules são P0.

Default:
deny.

Validar:

- public reads limitadas;
- customer somente próprios dados;
- Tenant Owner somente tenant próprio;
- Driver somente entregas autorizadas;
- Platform Admin via estratégia segura;
- cross-tenant bloqueado;
- cliente não altera price;
- cliente não altera role;
- cliente não confirma pagamento privilegiado;
- owner não cria Platform Admin.

Criar testes de Rules.
