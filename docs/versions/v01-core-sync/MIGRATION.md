# MIGRATION

Não há migração de cliente legado aplicada nesta versão porque o repositório de Sorveteria informado está vazio/novo.

A Sorveteria Sol de Verão é caso comercial e tenant de referência, mas dados não confirmados não devem ser tratados como produção.

Quando dados reais existirem:
- não substituir por seed;
- migrar com backup;
- preservar IDs quando possível;
- registrar transformação;
- validar Tenant A × Tenant B.
