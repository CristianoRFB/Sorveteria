# Screenshots reais

O Core recomenda screenshots reais como evidência de implementação.

Este diretório deve receber imagens capturadas do sistema EXECUTANDO, depois de QA.

Não colocar mockup ou imagem gerada fingindo ser screenshot real.

Sugestões mínimas futuras:
- landing SaaS;
- tenant alpha;
- tenant beta;
- Platform Admin;
- menu mobile;
- QR Code;
- checkout;
- tracking;
- driver;
- Rules/QA evidence quando visualmente útil.
