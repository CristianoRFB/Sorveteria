# v02 — Pricing Protocol / Commercial Architecture

Esta é a versão canônica do SaaS Sorveteria após aplicação do protocolo global de planos, pricing, entitlements, demo e refatoração de entregáveis.

## Regra mais importante

Esta versão **não afirma que entitlements, cobrança, checkout de assinatura ou feature gating por plano estejam implementados**.

Ela:

1. audita o estado real do ZIP v01;
2. inventaria funcionalidades;
3. propõe planos e preços específicos da vertical Sorveteria;
4. separa feature entitlement de usage limit;
5. define demo e landing comercial;
6. especifica o delta técnico necessário;
7. classifica NOW / NEXT / DEFERRED;
8. corrige mensagens do entregável que poderiam sugerir mais maturidade do que o código realmente possui.
